# PPT 自动相机（iPhone PWA）

一个只用 iPhone 上课即可运行的实验版：开始自动记录时先拍摄当前页，此后持续把实时画面与最近一次成功拍摄的照片画面比较，内容改变并重新稳定后自动拍摄。

## 重要限制
- 必须通过 HTTPS 或 localhost 打开，相机 API 才能工作；直接双击 index.html 不行。
- iPhone 页面需保持前台且不能锁屏。iOS 会限制网页后台相机。
- 网页无法等同于系统“相机”App 的完整高分辨率静态摄影管线。本项目保存相机视频流帧。
- “导出本节照片”在不同 iOS/Safari 版本上的多文件下载行为可能不同；必要时可逐张长按缩略图保存。

## 翻页检测原理（v5）
- 对白框区域生成低分辨率灰度帧，减少手机计算量。
- 使用 3×3 平滑抑制相机传感器噪声。
- 使用局部 SSIM 的结构/对比分量识别页面布局变化，并使用梯度边缘差异捕捉文字和线条变化。
- 始终与最近一次成功拍摄后建立的多帧平均参考图比较，而不是与单一瞬时帧比较。
- 每次拍摄后采集约 1.2 秒同页样本，自动估算当前手机、投影仪和现场光线的噪声上限。
- 触发门限根据现场噪声动态生成，并使用触发/恢复双阈值避免在临界值附近反复拍摄。
- 变化需持续约 0.6 秒才被确认；确认后等待新页面稳定，再保存高分辨率视频帧。
- 若投影刷新导致画面始终达不到“完全稳定”，最长等待约 2.5 秒后仍会保存，避免永久漏拍。
- 未检测到翻页时只会在差异远低于触发门限时缓慢更新同页基准，真实翻页不会被吸收。

### 方法依据
- Wang 等人的 SSIM 方法以结构信息而不是纯像素误差衡量图像相似度：https://doi.org/10.1109/TIP.2003.819861
- OpenCV 官方文档将 SSIM用于视频帧相似度比较：https://docs.opencv.org/5.0/tutorials/app/video_input_psnr_ssim.html
- OpenCV 官方文档说明 Sobel 将平滑与微分结合，对噪声具有一定抵抗力：https://docs.opencv.org/5.0/main_modules/imgproc_filter.html

## 推荐部署
最简单是把整个目录部署到任意支持 HTTPS 的静态网站托管服务。部署后用 iPhone Safari 打开 HTTPS 地址，允许相机权限，再通过 Safari 分享菜单选择“添加到主屏幕”。

## 使用
1. 手机固定在支架上，对准幕布。
2. 打开应用，点“启动相机”并允许摄像头。
3. 让白框主要覆盖 PPT，尽量减少讲台/观众。
4. PPT 当前页稳定后点“开始自动记录”，程序会先自动保存当前页作为对比基准。
5. 默认：检测灵敏度 6、稳定阈值 5、稳定时间 0.8 s、冷却时间 1.8 s。
6. 状态栏会显示 v5、实时差异、自动生成的门限、结构损失、边缘变化和检测阶段。
7. 漏拍可点“手动保存”。

## 调参
- 经常漏拍：提高“检测灵敏度”，如 6 → 8。
- 同一页重复拍摄：降低“检测灵敏度”，如 6 → 4；通常不再需要手动调整冷却时间。
- 翻页动画结束前就保存：提高“稳定时间”到 1.0~1.5 s。
- 连续重复拍：提高“冷却时间”。
- 画面一直显示“等待新页面稳定”：适当提高“稳定阈值”。

## 测试
运行 `python -m unittest discover -s tests -v`。测试覆盖整体亮度漂移、少量文字边缘变化、低幅传感器噪声、动态门限和 PWA 缓存版本。
