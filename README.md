# PPT 自动相机（iPhone PWA）

一个只用 iPhone 上课即可运行的实验版：相机持续观察投影幕，检测到页面发生较大变化并重新稳定后，自动保存当前高分辨率视频帧。

## 重要限制
- 必须通过 HTTPS 或 localhost 打开，相机 API 才能工作；直接双击 index.html 不行。
- iPhone 页面需保持前台且不能锁屏。iOS 会限制网页后台相机。
- 网页无法等同于系统“相机”App 的完整高分辨率静态摄影管线。本项目保存相机视频流帧。
- “导出本节照片”在不同 iOS/Safari 版本上的多文件下载行为可能不同；必要时可逐张长按缩略图保存。

## 翻页检测原理
- 对白框区域生成低分辨率灰度帧，减少手机计算量。
- 先补偿投影仪或相机自动曝光造成的整体亮度变化。
- 同时计算平均结构变化和显著变化像素占比，避免少量文字变化被大片相同背景稀释。
- 变化需持续约 0.24 秒才被确认；确认后等待新页面稳定，再保存高分辨率视频帧。

## 文件
- `index.html` 主程序
- `manifest.webmanifest` PWA 配置
- `sw.js` 离线缓存
- `icon.svg` 图标

## 推荐部署
最简单是把整个目录部署到任意支持 HTTPS 的静态网站托管服务。部署后用 iPhone Safari 打开 HTTPS 地址，允许相机权限，再通过 Safari 分享菜单选择“添加到主屏幕”。

## 使用
1. 手机固定在支架上，对准幕布。
2. 打开应用，点“启动相机”并允许摄像头。
3. 让白框主要覆盖 PPT，尽量减少讲台/观众。
4. PPT 当前页稳定后点“开始自动记录”。
5. 默认：变化阈值 6、稳定阈值 3、稳定时间 0.8 s、冷却 1.8 s。
6. 状态栏会实时显示“变化分数”；老师翻页后，程序等待新画面稳定再保存。
7. 漏拍可点“手动保存”。

## 调参
- 经常漏拍：降低“变化阈值”，如 6 → 4~5。
- 出现误拍：提高“变化阈值”，如 6 → 8~10。
- 翻页动画结束前就保存：提高“稳定时间”到 1.0~1.5 s。
- 连续重复拍：提高“冷却时间”。
- 画面一直显示“等待新页面稳定”：适当提高“稳定阈值”。

## 测试
运行 `python -m unittest discover -s tests -v`。测试覆盖整体亮度漂移、少量文字变化、低幅传感器噪声和 PWA 缓存版本。
